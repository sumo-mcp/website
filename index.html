Sumo MCP

An MCP server powered by historical and live data from sumo-api.com. This server helps AI chatbots like Claude and ChatGPT answer complex questions about sumo wrestling by providing access to comprehensive match data, wrestler statistics, tournament results, and rich historical records.

Easy to Use

Choose your preferred way to begin

一 • FIRST WAY

Through the Web

Connect instantly using our hosted endpoint through the "Connector" feature available in AI chat interfaces like Claude and ChatGPT. Simply add this URL to your Connector settings—no installation or configuration required. The Connector feature allows these AI assistants to directly query the sumo database in real-time, enabling them to answer detailed questions about wrestlers, matches, tournaments, and historical records with accurate, up-to-date information.

https://api.sumo-mcp.com/mcp
二 • SECOND WAY

Through Go

Install the Go toolchain on your system, then use this command as an stdio-based MCP server for desktop applications like Claude Desktop.

go run github.com/sumo-mcp/sumo-mcp/cmd@latest
